# Production RAG Benchmark v2

This directory defines the artifact contract used by the release gates.

The actual reviewed dataset is intentionally not generated by this patch. Add a
reviewed JSONL file and a manifest containing:

- dataset path;
- dataset SHA-256;
- embedding model;
- generation model;
- minimum case count;
- metric names;
- baseline thresholds;
- review version.

A benchmark without expert review should be treated as a smoke test rather than
a legal-quality oracle.
